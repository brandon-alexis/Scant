# Scant 

Aplicacion web para un concesionario llamado Scantd de venta de vehiculos tales como carros y motos, donde se podra consultar y cotizar todo el catalogo disponible.

# Instalacion

Para contribuir y hacer uso de la aplicacion clona el respositorio usando el siguiente comando
```sh
git clone https://github.com/brandon-alexis/Scant.git
```

o

Si tienes ssh

```sh
git clone git@github.com:brandon-alexis/Scant.git
```

Entra al directorio del proyecto e instala las dependencias
```sh
cd Scant
npm install 
```

# Iniciar el proyecto
Una estando el el proyecto con las dependencias descargadas, usa el siguiente comando para arrancar la aplicacion en modo desarrollo
```sh
npm run dev
```
